# AGES Enquiry Tracker

A simple enquiry and quote tracking tool for Ahmed Ghanim Electromechanical Services LLC.

## Features
- Quick enquiry capture (client, scope, contact, notes)
- WhatsApp quote parser — paste a quote message, auto-extracts client/scope/amount
- Status tracking (Enquiry Received → Quote Sent → Follow-up → Won/Lost/No Response)
- Follow-up date reminders
- OneDrive folder linking per enquiry
- Works on mobile and desktop, no login required

## Local development
```
npm install
npm run dev
```

## Deploy
This project deploys directly to Vercel or Netlify with zero configuration.
